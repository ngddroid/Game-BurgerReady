# Bun Voyage! — Burger Tycoon (Android)

An original 3D arcade-idle burger game for Android. You play an animal chef who grills, stacks and serves burgers, and builds a chain of **512 persistent restaurants** pad by pad (stations, tables, staff, drive-thru): the 12 of the Classic Voyage, then a 500-restaurant World Tour across 25 regions ([full list](docs/RESTAURANTS.md)). Everything you buy stays forever. When a restaurant is finished, it keeps earning idle income and the next one opens. Earnings also buy kitchen upgrades, chef skins, pets and room themes.

It's written in native **Kotlin**, using a custom **OpenGL ES 3 toon renderer** for the game and **Jetpack Compose** for all menus. Every model, illustration, icon, sound effect and music track is **generated by scripts in `tools/`** (Blender + Python), so the repository contains no third-party art.

> Project folder / package name: `BurgerReady` / `com.ngstudio.burgerready`. The player-facing name is **Bun Voyage!** ("Burger Ready" is already taken on Google Play). The package id is invisible to players, so it was kept.

## Quick start

### Requirements
- **Android Studio** (recent) with the Android SDK **API 37** platform installed. `local.properties` points at the SDK.
- **JDK**: Gradle provisions **JDK 25** automatically via foojay (`gradle/gradle-daemon-jvm.properties`); you don't need to install one.
- **Optional, only for regenerating assets:** **Blender 5.2** at `~/Applications/Blender.app`. Its bundled Python 3.13 + numpy is also used for audio. The system `python3` (3.9, no numpy) is enough for the verifier scripts.

| Toolchain | Version |
|---|---|
| Gradle / AGP / Kotlin | 9.6.0 / 9.4.1 / 2.2.10 (built-in Kotlin, Compose compiler plugin) |
| Compose BOM | 2026.02.01 |
| compileSdk / targetSdk / minSdk | 37 / 37 / 26 |

### Build, install, test
```bash
./gradlew assembleDebug                      # debug APK (≈41 MB, includes debug tools)
./gradlew assembleRelease                    # R8-minified release APK (≈29 MB)
./gradlew installDebug                       # install on the connected device/emulator
./gradlew :app:testDebugUnitTest             # all JVM tests, incl. the restaurant-flow validator (~20 s)
```
Outputs: `app/build/outputs/apk/{debug,release}/`.

### Run on an emulator
An AVD matching the target phone already exists on the original dev machine (`BunVoyage_720p`, 720×1600 at 320 dpi):
```bash
~/Library/Android/sdk/emulator/emulator -avd BunVoyage_720p -no-boot-anim -no-snapshot -gpu swiftshader_indirect -port 5580
```
- Use `-gpu swiftshader_indirect`; the host-GPU mode crashed this emulator twice ("Failed to find ColorBuffer").
- After boot, run `adb -s emulator-5580 shell wm density 320`.
- SwiftShader frame rates are **not** representative. Profile on a real phone.

## What's in the game

- **Core loop:** a floating joystick (drag anywhere). Cook at stations, carry a swaying stack, drop at the counter, stand at the register to serve, collect the cash stacks, spend them on glowing build/upgrade/hire pads. Also: tables and dirty trays, drive-thru cars, hired staff (cashier/runner/cleaner), combos, rush waves, VIPs, food critics, troubles (spill, grease fire, raccoon thief, jammed machine, sleepy guest), floor power-ups, periodic rush hours and critic visits, and a slow day cycle with a golden hour.
- **Restaurants:** 512 in total ([docs/RESTAURANTS.md](docs/RESTAURANTS.md)). The Classic Voyage has 12, Bun Wagon → Candy Kingdom; the World Tour adds 500 (25 regions × 20). Each has a fixed build plan of 15–44 pads, shown two at a time with guide arrows. Bigger restaurants bring bigger layouts, new menu items, a drive-thru and more staff.
  - No timer and no fail state. Customer patience only costs the sale and the combo.
  - The last pad, **NEW RESTAURANT**, opens the next location. Finished restaurants earn idle income (World tab), with renovation stars for more.
  - Pacing is checked by simulating every restaurant with a bot: ≈12.5 min for restaurant 1 and 15–33 min for later ones (expert bot).
- **Unlock rules:** only the Bun Wagon is open at first.
  - **Debug** builds: tapping the next locked restaurant offers a mock rewarded ad that opens it.
  - **Release** builds: the chip shakes and explains how to open it.
- **Story:** Chef Patty fills Hazel's *Voyage Book*, one page per restaurant, with a recurring cast (Hazel the mentor, Fenna the rival, Dot the regular, Scraps the raccoon, Clementine the critic). Speech-card beats on arrival, at milestones and on completion; a grand-opening finale; the Voyage Book (Play tab) to re-read everything. Script: [docs/STORY_SCRIPT.md](docs/STORY_SCRIPT.md).
- **World Tour:** after Candy Kingdom, 25 themed regions × 20 restaurants (500 more, 512 in all).
  - Each region: its own look, props, weather, menu lead, perk, host character and scenes.
  - A 20-stop rhythm that builds to a flagship.
  - A World Map, plus the Voyage Book's second part.
- **Late game:** the Golden Tour. Every finished restaurant has 3 gold stars (one-visit challenges) that pay gems and raise its idle income; 36 in all, with an epilogue.
- **Meta:** 8 kitchen upgrades, 512 restaurants (passive income, perks, renovations, different look in play), 11 chef skins, 5 pets, 8 themes, daily login calendar, lucky spin, daily tasks, a free daily chest, a Recipe Book (77 cards incl. 25 region stamps), 55 trophies, Chef Rank, a World Map.
- **Screens:** system splash → animated splash → onboarding (4 pages, **no skip**) → Home with a 5-tab bottom bar (Shop · Kitchen · **Play** · World · Style) → game HUD/pause/celebrations. Settings opens Terms and Privacy as new screens showing themed HTML from `assets/legal/`.

## Repository map

```
app/src/main/java/com/ngstudio/burgerready/
  App.kt, MainActivity.kt     app singletons (repo, audio, ads), quality tier
  engine/                     "Grill Engine": GLES3 instanced toon renderer, .bvm loader, camera, sprite atlas, particles
  game/                       pure-Kotlin simulation (no Android imports): World, restaurants + build plans, layouts, bots, economy
  render/                     bridges game ⇄ engine: GL loop, world drawing, joystick surface, HUD snapshot
  data/                       save/progress (GameRepo), catalogues (cards, achievements, rewards)
  audio/                      SFX (SoundPool), calm/rush music crossfade (AudioTrack), haptics
  ads/                        AdsProvider seam (DebugMockAds / NoAds)
  ui/                         Compose: AppRoot navigation, kit/ (game-styled widgets), screens/, theme/
app/src/test/.../game/        JVM tests: RestaurantFlowTest (pacing, reachability, save restore, determinism)
app/src/main/assets/
  models/   116 .bvm models          ui/      66 HD PNG renders (stores, skins, pets, cards, onboarding…)
  audio/    59 SFX + 6 music WAVs
  legal/    terms.html, privacy.html, style.css   fonts/ + licenses/  (OFL: Lilita One, Nunito)
tools/
  blender/  model + render scripts (bvlib.py is the shared library and .bvm exporter)
  audio/    procedural SFX/music synth (see tools/audio/README.md)
  icon/     launcher-icon sources + make_icons.sh, Play Store icon, feature graphic
  previews/ preview renders of every model (for eyeballing; not shipped)
docs/       design, architecture, developer guide, asset contract, QA report
```

## First commit
The folder isn't under version control yet. Before `git init`, add these to `.gitignore`:
```
__pycache__/
tools/previews/        # 41 MB of regenerable preview renders (optional to keep)
```
Never commit a release keystore or `local.properties`.
