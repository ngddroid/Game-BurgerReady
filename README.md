# Bun Voyage! — Burger Tycoon (Android)

An original 3D arcade-idle burger game for Android. You play an animal chef who grills, stacks and serves burgers across **10,000 level-based shifts**, then spends the earnings on kitchen upgrades, world **Stores** (passive income), chef skins, pets and room themes.

It's written in native **Kotlin**, using a custom **OpenGL ES 3 toon renderer** for the game and **Jetpack Compose** for all menus. Every model, illustration, icon, sound effect and music track is **generated by scripts in `tools/`** (Blender + Python), so the repository contains no third-party art.

> Project folder / package name: `BurgerReady` / `com.ngstudio.burgerready`. The player-facing name is **Bun Voyage!** ("Burger Ready" is already taken on Google Play). The package id is invisible to players, so it was kept.

## Quick start

### Requirements
- **Android Studio** (recent) with the Android SDK **API 37** platform installed. `local.properties` points at the SDK.
- **JDK**: Gradle provisions **JDK 25** automatically via foojay (`gradle/gradle-daemon-jvm.properties`); you don't need to install one.
- **Optional, only for regenerating assets:** **Blender 5.2** at `~/Applications/Blender.app`. Its bundled Python 3.13 + numpy is also used for audio. The system `python3` (3.9, no numpy) is enough for the verifier scripts.

| Toolchain | Version |
|---|---|
| Gradle / AGP / Kotlin | 9.6.0 / 9.4.1 / 2.2.10 (built-in Kotlin, Compose compiler plugin) |
| Compose BOM | 2026.02.01 |
| compileSdk / targetSdk / minSdk | 37 / 37 / 26 |

### Build, install, test
```bash
./gradlew assembleDebug                      # debug APK (≈41 MB, includes debug tools)
./gradlew assembleRelease                    # R8-minified release APK (≈29 MB)
./gradlew installDebug                       # install on the connected device/emulator
./gradlew :app:testDebugUnitTest             # all JVM tests, incl. the 10,000-level validator (~15 s)
```
Outputs: `app/build/outputs/apk/{debug,release}/`.

### Run on an emulator
An AVD matching the target phone already exists on the original dev machine (`BunVoyage_720p`, 720×1600 at 320 dpi):
```bash
~/Library/Android/sdk/emulator/emulator -avd BunVoyage_720p -no-boot-anim -no-snapshot -gpu swiftshader_indirect -port 5580
```
- Use `-gpu swiftshader_indirect`; the host-GPU mode crashed this emulator twice ("Failed to find ColorBuffer").
- After boot, run `adb -s emulator-5580 shell wm density 320`.
- SwiftShader frame rates are **not** representative. Profile on a real phone.

## What's in the game

- **Core loop:** a floating joystick (drag anywhere). Cook at stations, carry a swaying stack, drop at the counter, stand at the register to serve, collect coin piles, spend them on glowing build/upgrade/hire pads. Also: tables and dirty trays, drive-thru cars, hired staff (cashier/runner/cleaner), combos, rush waves, VIPs, food critics, troubles (spill, grease fire, raccoon thief, jammed machine, sleepy guest), floor power-ups, and day→dusk lighting per shift.
- **Levels:**
  - Levels 1–10 are handcrafted tutorials you cannot lose.
  - Levels 11–10,000 are generated deterministically from a difficulty curve: a sawtooth per 10-level chapter, a boss every 10th level, mutators from level 50.
  - Every level's star targets are tuned offline by simulating it with a bot.
- **Unlock rules:** only level 1 is unlocked at first; winning a level unlocks the next.
  - **Debug** builds: tapping a locked level offers a mock rewarded ad that unlocks it.
  - **Release** builds: the node shakes and shows "Finish Level N to unlock".
- **Meta:** 8 kitchen upgrades, 12 Stores (passive income, perks, renovations, different look in play), 11 chef skins, 5 pets, 8 themes, daily login calendar, lucky spin, daily tasks, a free daily chest, a Recipe Book (60 cards), 50 trophies, Chef Rank.
- **Screens:** system splash → animated splash → onboarding (4 pages, **no skip**) → Home with a 5-tab bottom bar (Shop · Kitchen · **Play** · Stores · Style) → game HUD/pause/results. Settings opens Terms and Privacy as new screens showing themed HTML from `assets/legal/`.

## Repository map

```
app/src/main/java/com/ngstudio/burgerready/
  App.kt, MainActivity.kt     app singletons (repo, audio, ads), quality tier, level-target loading
  engine/                     "Grill Engine": GLES3 instanced toon renderer, .bvm loader, camera, sprite atlas, particles
  game/                       pure-Kotlin simulation (no Android imports): World, levels, layouts, bots, economy
  render/                     bridges game ⇄ engine: GL loop, world drawing, joystick surface, HUD snapshot
  data/                       save/progress (GameRepo), catalogues (cards, achievements, rewards)
  audio/                      SFX (SoundPool), calm/rush music crossfade (AudioTrack), haptics
  ads/                        AdsProvider seam (DebugMockAds / NoAds)
  ui/                         Compose: AppRoot navigation, kit/ (game-styled widgets), screens/, theme/
app/src/test/.../game/        JVM tests: level validator, tuner, smoke test
app/src/main/assets/
  models/   116 .bvm models          ui/      66 HD PNG renders (stores, skins, pets, cards, onboarding…)
  audio/    59 SFX + 6 music WAVs     levels/  targets.bin (tuned star targets for all levels)
  legal/    terms.html, privacy.html, style.css   fonts/ + licenses/  (OFL: Lilita One, Nunito)
tools/
  blender/  model + render scripts (bvlib.py is the shared library and .bvm exporter)
  audio/    procedural SFX/music synth (see tools/audio/README.md)
  icon/     launcher-icon sources + make_icons.sh, Play Store icon, feature graphic
  previews/ preview renders of every model (for eyeballing; not shipped)
docs/       design, architecture, developer guide, asset contract, QA report
```

## First commit
The folder isn't under version control yet. Before `git init`, add these to `.gitignore`:
```
__pycache__/
tools/previews/        # 41 MB of regenerable preview renders (optional to keep)
```
Never commit a release keystore or `local.properties`.
