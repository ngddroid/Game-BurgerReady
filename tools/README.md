# tools/ — asset pipeline

Every 3D model, HD illustration, icon, sound and music track in the game is **generated by the scripts here**. To change an asset, edit its script and re-run it. Never hand-edit a generated file.

| Output | Generated by | Lands in |
|---|---|---|
| 3D models (`.bvm`) | `blender/*.py` | `app/src/main/assets/models/` |
| HD UI art (PNG, transparent) | `blender/render_ui.py`, `blender/render_cards.py` | `app/src/main/assets/ui/` |
| Launcher icon, Play icon, feature graphic | `blender/render_ui.py -- icon` + `icon/make_icons.sh` | `tools/icon/`, `app/src/main/res/mipmap-*`, `res/drawable-nodpi/splash_icon.png` |
| SFX + music (WAV) | `audio/synth.py` | `app/src/main/assets/audio/` |
| Preview renders for eyeballing | all model scripts | `tools/previews/` (not shipped) |

## Requirements
- **Blender 5.2** at `~/Applications/Blender.app`. Every Blender script runs headless:
  ```bash
  BLENDER=~/Applications/Blender.app/Contents/MacOS/Blender
  $BLENDER -b --factory-startup --python tools/blender/<script>.py -- <args>
  ```
  Blender exits 0 even after a Python traceback, so check the log for `Traceback`. `build_all.sh` does this for you.
- Rendering uses Cycles on the Metal GPU when available, otherwise the CPU.
- Verifier scripts are plain Python: `python3 -I …` (no numpy needed).

## blender/

### Library
| File | Purpose |
|---|---|
| `bvlib.py` | Shared library for every script: palette (`PAL`), flat palette materials `mat(color, tint=…, emit=…)`, primitives, pivots/joins, anchors (`@name` empties), **AO bake**, the **`.bvm` exporter** (format documented in its docstring) and quick preview renders |
| `kit.py` | Extra helpers for props (lathe, loft, tube, rounded boxes…), and `run(MODELS)`, which resets the scene, builds, exports and previews each entry of a script's `MODELS` table |

**Conventions** (full spec: [`docs/ASSET_CONTRACT.md`](../docs/ASSET_CONTRACT.md)):
- 1 unit = 1 m. Blender is Z-up; **front = −Y**. The exporter converts to engine Y-up: (x, z, −y).
- A model = **parts** (one mesh object each; origin = pivot; Blender parenting = part hierarchy) + **anchors** (empties named `@…`).
- Colours come only from `bvlib.mat()`. AO is baked into the vertex colours on export.
- `tint=True` marks faces the engine recolours: shirts, trims, chair seats, car bodies. Use a near-white base colour on those faces.
- `emit=` marks glowing parts (lamps, neon, screens). They glow more at night.
- Each model has a triangle budget (see the contract). Exports print `EXPORTED … tris=`.

### Model scripts
| Script | Models | Run |
|---|---|---|
| `food.py` | `food_*` (burger, cheese, double, veggie, fries, soda, shake, tray, bag, coin, gem, patty_raw) | `-- [model names]` |
| `stations.py` | `st_*`, counter, drive_window, tables, chair, trash bin, pads, register stand | `-- [model names]` |
| `building.py` | floors, ground tiles, walls, windows, posts, door frame, road, crosswalk | `-- [model names]` |
| `env.py` | trees, palm, bushes, planters, lamps, bench, menu board, neon sign, umbrella, car, van, scooter, cloud | `-- [model names]` |
| `stores.py` | `store_<store>_<prop>` (3 signature props for each of 12 stores) | `-- [model names]` |
| `characters.py` | `char_<species>` (10 animals; rigid parts for procedural animation) | `-- [species] [--no-preview] [--no-lineup]` |
| `hats.py` | `hat_<name>` (10 hats, built around a shared 0.36 m skull ring) | `-- [names] [--no-preview]` |
| `pets.py` | `pet_<name>` (5 pets) | `-- [names] [--no-preview]` |
| `build_all.sh` | Runs food, stations, building, env, stores, then `scenes.py`, then `verify_models.py` (≈4 min) | `tools/blender/build_all.sh [--noprev]` |

Each prop script has a `MODELS` dictionary: `name → (builder, tri budget, export options)`. To add a model, add a builder function and an entry there.

### Render scripts (UI art)
| Script | Produces | Run |
|---|---|---|
| `render_ui.py` | `skin_<id>` 512², `pet_<id>` 512², `card_guest_<species>` 256², `onboard_1..4` 1024², icon set (`tools/icon/icon_full/fg/bg.png`, `feature_graphic.png`) | `-- [skins pets cards onboard icon] [--only=<id>] [--fast]` (full run ≈6–8 min) |
| `render_cards.py` | `store_<id>` 640×512, `theme_<id>` 512², `upgrade_<id>` 256², `card_food_<id>` 256² | `-- [name prefixes, e.g. theme_ store_lodge]` |
| `scenes.py` | Composite scene checks in `tools/previews/scenes/` (not shipped) | — |

UI renders use Subdivision Surface + smooth shading for HD quality; this applies to renders only, not to the game `.bvm` files. They have soft round contact shadows and a fully transparent background. Files over ~400 KB are palette-quantised.

The catalogues the renders iterate over (`SKINS` in `render_ui.py`; `STORE_SPECS`, `THEMES`, `ICONS`, `FOODS` in `render_cards.py`) must stay in sync with `game/Economy.kt` and `game/Types.kt`.

### Checking models
```bash
python3 -I tools/blender/verify_models.py            # props/food/stations/building/stores vs the contract (exit 1 on failure)
python3 -I tools/blender/inspect_bvm.py char_corgi   # parts, parents, pivots, tris, tint/emissive counts, anchors
python3 -I tools/blender/inspect_bvm.py --all        # one line per model: tris and size
```
After re-exporting a character, check its part order and anchors with `inspect_bvm.py`: the engine animates by part name and attaches hats/stacks/bubbles to `@hat`, `@hand`, `@bubble`.

`pipeline_test.py` is the original exporter smoke test. It writes `assets/models/test_burger.bvm`, so delete that file after running it.

## icon/
| File | What |
|---|---|
| `icon_full.png` | 1024² opaque icon (legacy/round icons, Play Store icon) |
| `icon_fg.png` / `icon_bg.png` | Adaptive icon layers. The foreground content must stay inside the central 66 % circle |
| `icon_mono.png` | Monochrome (themed-icon) layer, generated from the fg alpha |
| `play_store_icon_512.png`, `feature_graphic.png` | Play Console assets (512² icon; 1024×500 feature graphic with the title) |
| `make_icons.sh` | Builds all launcher densities + the monochrome layer + the splash icon, and rewrites `mipmap-anydpi-v26/ic_launcher*.xml` |

**Regenerate:**
```bash
$BLENDER -b --factory-startup --python tools/blender/render_ui.py -- icon
# The shipped foreground was enlarged ~16 % after rendering so the chef reads better in circular masks:
sips --cropToHeightWidth 880 880 tools/icon/icon_fg.png --out tools/icon/icon_fg.png && sips -z 1024 1024 tools/icon/icon_fg.png
zsh tools/icon/make_icons.sh
```
⚠️ `make_icons.sh` deletes the old `res/drawable/ic_launcher_*.xml` and `mipmap-*/ic_launcher*.webp` template icons on purpose.

## audio/
Procedural synthesis (numpy, run through Blender's Python). See [`audio/README.md`](audio/README.md) for the instruments, the QC checks, loop rules and the per-sound volume trims.
```bash
$BLENDER -b --factory-startup --python-exit-code 1 --python tools/audio/synth.py -- all     # ~10 s, deterministic
```
The list of sound names is `audio/sfx_list.txt`. The game plays them by name via `App.sfx("name")`.
